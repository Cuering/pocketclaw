# PocketClaw

A floating Android overlay that uses on-device Gemma 4 E2B to explain, summarise, or answer questions about whatever you're looking at on your screen. Fully offline. Fully private.

Built for the [Gemma 4 Challenge](https://dev.to/challenges/google-gemma-2026-05-06) — May 2026.

## Status

🚧 In active development. Submission deadline: May 24, 2026.

## Stack

- Flutter 3.41 / Dart 3.11
- Gemma 4 E2B via `flutter_gemma`
- Android MediaProjection for screen capture
- `flutter_overlay_window` for the floating bubble
- Play Asset Delivery for model distribution
